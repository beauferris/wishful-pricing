# Theme folder (removed)

Legacy Liquid snippets that duplicated `extensions/wishful-pricing-storefront/` were removed to avoid drift and App Store review confusion.

**Supported storefront setup:**

1. Deploy the app: `npm run deploy`
2. **Online Store → Themes → Customize → Product** → main product section → **Add block** → **Wishful pricing** (Apps)

Canonical storefront code: `extensions/wishful-pricing-storefront/`.

See `docs/THEME-BLOCK-SETUP.md` and `docs/APPROVAL-CHECKLIST.md`.
