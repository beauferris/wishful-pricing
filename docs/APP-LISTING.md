## App name

Wishful Pricing

## Tagline (subtitle)

Size, quantity, and volume discounts with live product-page pricing.

## App introduction (short)

Configure custom pricing for stickers, transfers, and similar products using size × quantity tables, flat size bands, or volume breaks. Optional B2B account discounts apply a percentage off retail. Checkout discounts run automatically via Shopify Functions.

## App details (long)

Wishful Pricing helps merchants sell made-to-size products without manual price edits.

**In the Shopify admin**

- Create an automatic discount and open the **Wishful pricing** card on the discount details page.
- Choose which products use each rate table (opt-in only — empty list means no discount).
- Set pricing mode: area × quantity, flat price per size band, or volume-only quantity breaks.
- Configure area bands, quantity tiers, per-variant rate tables, optional line-item adjustments, and B2B account tiers (% off retail).
- Click **Save pricing** to sync discount configuration and storefront metafields.

**On the storefront**

- Add the **Wishful pricing** theme app block on the product template (**Online Store → Themes → Customize → Product**).
- Customers enter width and height (or quantity-only for volume products); the product page preview matches checkout.
- Uninstalling the app removes app blocks — no Asset API or leftover theme code.

**Plans**

Works on all Shopify plans when installed from the Shopify App Store. No Shopify Plus required.

## Key features (bullets)

- Area × quantity pricing ($ per sq in)
- Flat price per size band (Cad-Cut style)
- Volume / quantity-only pricing
- Per-variant rate tables
- Optional line-item adjustments (e.g. add-on fees)
- B2B / account pricing (% off retail via customer tags or metafield)
- Product-page price preview
- Automatic checkout discounts

## Demo / setup instructions for reviewers

1. Install the app on the test store.
2. Go to **Discounts** → **Create discount** → automatic discount.
3. Select the discount type powered by **Wishful Pricing** / the app’s product discount function.
4. Open the discount → use the Wishful settings card → choose products → configure tiers → **Save pricing**.
5. **Online Store → Themes → Customize** → Product template → main product section → **Add block** → **Wishful pricing** (Apps).
6. Open a configured product, set width/height (or quantity), add to cart, and verify checkout discount matches the product-page preview.
7. Optional — B2B: add an account tier (e.g. key `wholesale`, 10% off), tag a test customer `wholesale`, log in, re-add to cart, confirm storefront and checkout both show the reduced rate.
8. Optional: remove a product from the discount → **Refresh storefront** → confirm the product page no longer shows the calculator.
